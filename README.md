# Dayfolk website

English travel-planning prototype. Static HTML and CSS, ready for GitHub Pages.

The site uses relative asset paths and works under a project URL or a custom domain.
Activity information is a dated research snapshot; no booking or live availability is guaranteed.
Photo sources and reuse licenses are listed in credits.html.

Only public website files belong in this repository. Development notes, research
logs, test choices and full development history belong in the private project repository.

To host: GitHub Settings → Pages → Deploy from a branch → main → /(root).
Add a custom domain only after its owner has configured DNS.
